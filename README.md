# ACE Roofing — aceroofingtx.com

Static rebuild of [aceroofingtx.com](https://www.aceroofingtx.com/). It is plain HTML, CSS and JavaScript, with no build step and no dependencies. It can be hosted on GitHub Pages, Netlify, Cloudflare Pages or any web host.

The URLs match the current site, so existing Google rankings and links carry over.

Shared files:

- `tools/build.py`: generates every page (content, titles, descriptions, structured data).
- `assets/css/styles.css`: all styling, inlined into each page at build time. Brand colors and fonts are at the top (`--gold`, `--black`, etc.).
- `assets/js/main.js`: mobile menu, gallery lightbox and contact forms, inlined at build time.
- `sitemap.xml`, `robots.txt`, `404.html`

## Before going live

1. **Forms.** Both forms are sent through [Web3Forms](https://web3forms.com) (account aceco@aceroofingtx.com), which emails each request and logs it in the Web3Forms dashboard. The access key is `FORM_ACCESS_KEY` at the top of `assets/js/main.js`; recipients are changed in the Web3Forms dashboard.
2. **Images.** Images are still loaded from the current website host (`irp.cdn-website.com`). They will disappear if that account is cancelled. Run `scripts/localize-images.sh` from the repo root to download them into `assets/images/` and update every page to use the local copies.
3. **Hosting / domain.** For GitHub Pages: go to Settings → Pages, deploy from `main`, root folder, then set the custom domain to `www.aceroofingtx.com`.

## Making changes

Pages are generated by `tools/build.py` (page text, titles, SEO data) together with `assets/css/styles.css` and `assets/js/main.js`. Edit those, then run:

```
python3 tools/build.py
```

The build minifies the CSS and JS and inlines them into every page, so nothing blocks the first paint. Do not edit the generated `index.html` files directly; the next build overwrites them.
